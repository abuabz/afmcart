# Afm Cart

Afm Cart is a Next.js storefront for gifts, toys, and jewellery, with product administration, online order management, and guest order tracking.

## Local Development

```powershell
npm install
npm run dev
```

Configure `MONGODB_URI`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, and `JWT_SECRET` in `.env.local` before starting the server. Product images are served from `public/uploads`.
